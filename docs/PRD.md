# 合规哨兵 PRD v0.3.6

> 版本：v0.3.6（验收依据为 SPEC v0.7；与 ARCHITECTURE、openapi.yaml、CONVENTIONS 同步）
> 日期：2026-10-26
> 产品：合规哨兵 — 内容合规体检（广告法 / 平台规则 / AI 标识）
> 状态：范围冻结，进入实现收口

## 1. 问题陈述

一人公司、接商单的自媒体作者，在"写完稿 → 点发布"之间有一道没人管的空档。他们既没有法务，也没有平台规则的明文，只能靠猜；猜错的代价是限流、下架，严重时是罚款。

现在的解法有四种，每种都解决不了这件事：

- 免费查词工具（零克查词、句易网）：只告诉你哪个词变红，不给依据、不给改法；免费额度一天 3 次，误判还要自己一条条分辨（测评提到约 15% 误判率〔S2〕）。
- 平台官方预检（公众号后台检测、小红书草稿预检、抖音发文检测）：最准，但只能检自己平台，一篇内容发五个平台要检五次，且同样只标红。
- 内容安全 API（网易易盾、阿里云内容安全）：能力最强，但按调用量计费、资源包年付起步（阿里云 300 万次年包 4590 元）〔S3〕，面向平台方与团队，个人创作者没有自助小额入口，也不给"这句话怎么改"。
- 人工法务 / 审核外包：律所单项文案审查"千元级起步、3-5 个工作日"〔S4〕；按篇外包 5-50 元/篇〔S5〕。贵且慢，赶不上当天的发布节奏。

2025 年 9 月 1 日《人工智能生成合成内容标识办法》施行，第十条要求用户发布生成合成内容时主动声明并使用平台标识功能，未标识内容可能被限流、下架〔S1〕。这条新规把"AI 味稿子要不要标"变成必须回答的问题，而免费查词工具基本不覆盖。

## 3. 核心使用场景（发布前体检）

1. 作者在编辑器里写完一篇 800 字小红书笔记，复制正文。
2. 打开合规哨兵，粘贴进输入区；如果稿子用过 AI 辅助，勾选"包含 AI 生成内容"。
3. 点击"开始体检"，2 秒内出结果：顶部一条总览（高风险 2 / 中风险 3 / 低风险 4，耗时 320ms），下面是逐条风险清单。
4. 清单每条给三样东西：**命中的原句**（带上下文，不是孤立词）、**依据**（《广告法》第九条 / 平台规则 / 标识办法第十条，条文号不确定时只写规则名）、**可以直接替换的写法**。
5. AI 标识项单独一块：勾了 AI 内容但正文没有显式声明的，给出高风险提示和一句可直接粘贴的声明话术。
6. 作者按建议逐条改稿，改完再体检一次，高风险清零，去发布。
7. 底部原样展示接口 `disclaimer` 字段全文，前端不得截断、不得改写：本工具仅提供内容风险自查参考，不构成法律意见，不替代平台审核，不保证发布结果。涉及具体法律问题请咨询专业律师。

### 能力边界（措辞纪律，对外文案与免责声明必须一致）

- 我们**不做 AI 生成内容检测**，也没有这个能力。做的是"作者自述含 AI 内容时，检查正文有没有按《标识办法》加显式声明"。文案里不得出现"检测出这是 AI 写的"这类表述。
- 我们不承诺"保证通过审核"。交付的是可执行的自查结果，审核结论由平台作出。
- 规则库版本号是对外口径字段（`/api/v1/meta` 的 version 会显示在首页），发布前必须是 `2026.10` 这类版本号，不得带 demo、测试、草稿字样。

## 4. P0 功能清单（与冻结范围对齐）

| # | 功能 | 验收要点 |
|---|---|---|
| 1 | 单页工具：粘贴检测（1–20000 字） | 提交后按第 10 节性能口径返回规则结果；超过 20000 字返回 422 并由前端转成中文提示"单次最多 20000 字，请分段检测"，**不截断、不静默检测**（截断会漏报，比报错严重） |
| 2 | 规则库 100 条，分六类：广告法 / 医疗健康 / 教育培训 / 金融理财 / 平台规则 / 通用表达（**分类名与条数分布以 SPEC v0.4 为准，不再变更**；AI 标识不作为规则分类，由第 4 项单独承担）。首交分布：广告法 38 / 医疗健康 22 / 平台规则 16 / 金融理财 10 / 教育培训 8 / 通用表达 6 | 每条含 category、level、basis、suggestion、exempt；条文号不确定只写规则名；上线前双人复核；入库校验禁止两条规则出现"相同 pattern 且相同 suggestion" |
| 3 | 风险清单（报告区） | 每条返回 matched / start / end / basis / suggestion / note / suggestion_source（rule 或 llm）。**列表排序：先按等级 high → medium → low，同级内按 start 升序，同一位置多条按 level → rule_id**（风险优先，便于用户先处理最严重的；排序规则以 SPEC 为准） |
| 4 | AI 标识检查（判定保守，宁可多提示） | 勾选含 AI 内容且正文无显式声明 → 返回 high 级 ai-label-missing，附可直接粘贴的声明话术。判定要求：① 标识用语清单扩到 12–15 条常见变体（含"本文由AI辅助完成""内容由AI生成""AI创作""本文含AI生成内容"等写法）；② 比对前做归一化（全角转半角、去空格），避免用户写了却被判缺失；③ **不限标识位置**，起始、末尾、中间任一处出现即算已声明（《标识办法》第四条允许三种位置）。接口层与风险清单共用 findings，`rule_id` 固定 `ai-label-missing`、matched 为空、start/end 为 0；页面按 rule_id 过滤后单独成块，不混排、不按位置定位 |
| 5 | 降级路径 | LLM 未配置或超时（2 秒）仍返回完整规则结果，建议降级为规则模板，页面不报错；`suggestion_source` 如实标注 rule / llm，供后续评估模型改写质量 |
| 6 | 基础埋点 | 服务端在每次检测时记：耗时、命中条数、分级分布、是否勾选 AI、按 rule_id 的命中计数（键上限 100，均不含原文）。前端经 POST /api/v1/events 上报**两个事件：suggestion_copied（采纳率唯一来源）、error_occurred**；`check_submitted` 仅服务端产生，前端上报被忽略；白名单外事件一律忽略，不得借该通道传自由文本 |
| 7 | 公网部署 | PC 与手机浏览器可访问；/api/v1/health 通过；首页 3 秒内展示规则库统计 |
| 8 | 限流 | 同 IP 一小时 >60 次返回 429，响应带 Retry-After（秒），文案与秒数同源："本次检测额度已用完，约 N 分钟后可再次检测"；前端按秒数禁用提交 |
| 9 | 空态与错误态 | 未输入点检测给引导而不是报错；**零命中固定文案：「未发现明显违规表述，建议发布前再用平台官方预检复核一遍」，并显示 /meta 的规则总数，禁用"完全合规"这类结论**；服务不可用给"稍后再试 + 人工复核建议"，不显示技术堆栈与英文报错 |

## 5. 差异化（一句话）

> 免费工具只标红让你自己猜，法务审一篇千元起要等三天；合规哨兵 30 秒给出「哪句话有问题 + 依据哪一条 + 换成什么」。

这句话站得住的三点支撑：一是市面免费工具普遍只做词命中、不附依据与改写（对比见第 9 节）；二是我们把「AI 标识」并进同一次体检，这是 2025 年 9 月新规之后新增的必答题，免费查词工具没有覆盖；三是不做"保证通过审核"的承诺，只交付可执行的改写（CONVENTIONS 第 2 条）。

## 6. MVP 不做的范围

| 不做 | 原因 |
|---|---|
| 视频 / 音频检测 | 三周内无法保证准确率与成本，不做半成品 |
| 涉政涉黄深度词库 | 误报与合规风险高，超出"商业内容合规"定位 |
| 小程序 / App | 需资质与审核周期，网页链接已满足演示与报名 |
| 用户系统 / 在线支付 | 首交前不引入转化摩擦；付费只做意愿验证（留资/口头） |
| 历史记录 / 批量检测 | 需账号体系支撑，进 11 月 Backlog |
| 模型训练 / 微调 | 无数据与算力必要性，规则 + 可选 LLM 已够 |
| 数据库与原文留存 | 不留存用户文稿，既是隐私承诺也是成本控制；需要留痕时只留计数，不留正文 |
| 用户体系、鉴权、多租户 | 与"零门槛单页"冲突，且首交前不引入注册墙 |
| 规则热更新与灰度、容器化、监控平台 | 100 条规则走 Git 版本管理 + 重启生效足够，上基础设施是过度工程 |
| 开放 API / 插件 | 非 MVP 验证目标 |
| 自动发布到各平台 | 涉及平台授权与责任边界，明确不做 |

## 7. 验证指标

| 指标 | 口径（写死，避免上线后各自解释） | 目标 |
|---|---|---|
| 有效试用人数 | 拿到链接的自然人，24 小时内提交 ≥2 次检测，且至少 1 次复制了某条建议或点了"已按此修改" | 分层记录：触达 ≥20 人、有效 ≥10 人（上线 5 天内）；不达标如实写，不改口径 |
| 二次使用率 | 首次使用后 7 天内再提交 ≥1 次的人数 / 有效试用人数 | ≥30% |
| 建议采纳率 | 被复制或标记已采纳的命中条数 / 总命中条数 | ≥25% |
| 误报率 | 随机抽 50 条命中（按 rule_id 分层，high/medium/low 都要覆盖），两名评审独立判定"该命中在原语境是否成立"（有明确依据且确实构成风险），不一致时由第三人裁定；误报率 = 不成立条数 / 50。**因命中窗口内出现豁免关键词（引用/转述/不得使用）而由 high 降为 low 的条目，不计入分子，另计"降级合理性"抽查 10 条** | ≤20%（第三方测评基线约 15%〔S2〕，首版允许略高） |
| 关键违规召回 | 取 10 篇公开处罚案例中的违规表述（如功效承诺、虚假人设类），逐篇体检，命中 ≥1 条 high 记为通过 | ≥7/10 |
| 付费意愿 | 试用结束时问一句"如果 19 元/月不限次，你会买吗"，记录明确"会"的人数 | ≥5 人（只测意愿，不收款） |
| 平均检测耗时 | 后端 elapsed_ms 的 p95；规则链路与 LLM 链路分开统计 | 规则链路稳态 p95 ≤100ms、含冷启动首请求 ≤200ms；默认模式（不配 LLM）/check 全链路 ≤2s；LLM 开启时不计入规则 p95，超时降级不计为失败、单独记降级率 |

抽样方法：误报率与召回样本、判定记录全部留档在 docs/validation/，供赛事答辩复现；不编造数据（CONVENTIONS 第 1 条）。

## 8. 种子用户获取路径（10-20 人，不依赖粉丝）

按"能私聊到具体的人"排序，不投流、不群发：

| 渠道 | 具体动作 | 预期 |
|---|---|---|
| 平台吐槽帖作者 | 在小红书、即刻搜"限流""违规""申诉"，筛近 7 天发帖、粉丝 <5000 的作者，逐条私信说明来意并附链接（每人不同开场，不复制粘贴） | 私信 40 → 回复 10 → 试用 6 |
| 熟人定向私聊 | 朋友圈发 1 条 + 单独私聊 10 位在写公众号/接商单的朋友，请他们用自己最近一篇稿子试 | 试用 8 |
| 一人公司社群 | 独立开发者群、创业者群、本地创业孵化器微信群，发一条"免费体检 3 篇"的求助式征集 | 试用 4 |
| 商家侧切入 | 找 3 位给本地商家写小红书的兼职写手，让他们拿客户稿来测（客户稿违规风险最高） | 试用 2 |

执行纪律：每个试用者 24 小时后回访一句"哪条你觉得多余"，把原话记进误报台账；不承诺"保证过审"。

## 10. 非功能与埋点

| 类别 | 要求 |
|---|---|
| 性能 | 首交版本**不配 LLM 密钥**，建议全部来自规则模板：规则链路稳态 p95 ≤100ms、含冷启动首请求 ≤200ms，默认模式 /check 全链路 ≤2s。LLM 改写为可选能力，仅演示时开启，超时统一 2 秒即降级，该链路不计入规则 p95（原 800ms 与 12 秒超时口径均作废）。首页 3 秒内展示规则统计 |
| 安全与隐私 | 全站 HTTPS；输入校验与长度上限；同一 IP 每小时 60 次、超限 429 带 Retry-After。文本仅用于内存中的本次检测，不落库、不保存、不用于任何训练；配置 LLM 时只把命中的片段外发（最多 8 条，不含全文、不含 IP、不含时间戳）；访问日志脱敏，不存原文与 IP |
| 兼容 | Chrome / Safari / Firefox 最新两个版本；iOS、Android 微信内置浏览器 |
| 可访问性 | 键盘可达；正文与背景对比度达 WCAG 2.1 AA；风险等级不只靠颜色区分（附文字标签） |
| 图标 | 统一 Lucide（ISC）SVG sprite（`assets/icons.svg` + `<use>`），描边 1.75，尺寸仅 16/20/24px，颜色跟随 Token；不使用表情符号作为功能图标，不混用第二套图标库 |
| 埋点 | 服务端事件：check_submitted（含 elapsed_ms、finding_count、by_level{high,medium,low}、rule_hits{rule_id: 次数}、has_ai_content 布尔）；前端事件：suggestion_copied、error_occurred（经 POST /api/v1/events，批 ≤20 条、事件名白名单、无自由文本字段）。统一字段：event / timestamp / device / error_code；均不含原文与 IP。误报抽样的取数方式：从 check_submitted 的 JSON 行按 rule_id 聚合，低频规则优先抽取，不建库 |
